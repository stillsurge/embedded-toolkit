# PCB 布局自查清单（hw-pcb-review）

**layout 完成、打板之前过一遍——原理图对了布局错了照样翻车。**

去耦电容离芯片 3cm 等于没放、信号跨分割地平面回流绕行、晶振底下走高速线、TVS 离接口远保护形同虚设——这些 layout 阶段的事故全在原理图审查之外，本技能 9 大类 49 项清单兜住它们。

## 它解决什么问题

| 你遇到的 | 它给你的 |
|----------|----------|
| 打板回来功能不稳、EMC 测不过 | 9 大类布局自查：电源布局/回流地平面/晶振时钟/高速阻抗/EMC ESD/散热/接口/LED/装配 |
| 不知道哪些布局问题会翻车 | 每项带严重级别（必改/待确认/提示）+ 典型事故说明 |
| 外包 layout 没法验收 | 把清单当验收附件逐项打勾 |
| 板回来"玄学问题" | 60% 的玄学问题布局埋的——按类反查 |

## 9 大类速览

电源布局与去耦（8 项）/ 回流与地平面（5 项）/ 晶振与时钟（5 项）/ 高速与阻抗（7 项）/ EMC 与 ESD（6 项）/ 散热（4 项）/ 接口与连接器（4 项）/ LED 与指示（3 项）/ 装配工艺（7 项）——明细见 `references/pcb-checklist.md`。

## 作为 Agent Skill 使用

装进任意支持 Agent Skill 标准的 AI 助手后，直接说人话："帮我过一遍 PCB 布局，重点电源和 USB" / "这块板 EMC 测不过，布局上可能哪里有问题" / "打板前帮我自查一遍"。

### 包结构

- `SKILL.md` —— 技能说明书（AI 按需读取）
- `references/pcb-checklist.md` —— 9 大类 49 项明细（判据+典型事故）
- `scripts/pcb_check.py` —— 打勾工具（逐项过/没过/不适用，进度存档，自动出整改清单与通过率，支持导出 Markdown 报告）

## 打勾工具用法

```bash
python scripts/pcb_check.py run --board "板名"    # 交互逐项检查（跨会话续查）
python scripts/pcb_check.py report --board "板名" # 整改清单（按严重级别排序）
```

## 定位边界

纯清单型自查工具，**不看 Gerber 文件**（审查对象是你描述的布局特征或截图内容）；与 `hw-review-checklist`（原理图审查）配合——两张清单都过完才打板。

## 复核方式

清单条目均为公开工程惯例，逐条核对依据：判据内含具体数值（如去耦电容 ≤2mm、板边 ≥5mm）的条目来自器件 datasheet 与 SI 专家通用建议；拿不准的条目按"待确认"级别处理，需计算确认的走 `hw-calc`。

## 真实输出样例

问：「USB 枚举不稳定，眼图闭合，布局上会是什么？」

> **先查两条（必改级）**：
> 1. D+/D- 差分等长（±0.5mm 内）——不等长直接眼图闭合
> 2. 差分对参考平面完整——跨分割回流绕行同样闭合
> 再查：90Ω 阻抗控制与叠层匹配、对间距离 ≥3W、ESD 器件是否在 D+/D- 上且靠近接口。
> 依据：清单 D1/D3/D5 项。
