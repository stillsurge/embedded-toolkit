# PCB 布局自查清单（hw-pcb-review）

原理图对了、布局错了照样翻车：去耦电容离芯片 3cm 等于没放、回流路径被分割地平面切断、晶振底下走高速线。本清单管 **layout 阶段**的自查——9 大类，每项 = 检查内容 + 严重级别 + 典型事故。

与 `hw-review-checklist`（原理图审查）互补：**先过原理图清单，再过本清单，两关都过才打板。**

## 何时使用

- layout 完成、准备打板前 → 逐类自查
- 拿到外包/layout 公司的图 → 审查验收
- 板子回来功能不稳/EMC 测不过 → 反查布局原因

## 9 大类速览

| 类 | 覆盖 | 典型事故 |
|---|---|---|
| A 电源布局 | DC-DC 环路最小化、去耦电容位置、大电流路径宽度 | 去耦电容离芯片过远=高频噪声无回路 |
| B 回流与地平面 | 地平面完整性、分割处理、跨分割信号 | 信号跨分割→回流绕行→EMI 与串扰 |
| C 晶振与时钟 | 晶振包地、时钟走线等长、远离板边 | 晶振下方走高速线→时钟抖动 |
| D 高速与阻抗 | 阻抗控制（USB/CAN/DDR）、差分等长、端接位置 | USB D+/D- 不等长→眼图闭合 |
| E EMC 与 ESD | ESD 器件位置（靠近接口）、共模电感、屏蔽地 | ESD 器件离接口远→保护形同虚设 |
| F 散热 | 功率器件铜箔面积、过孔阵列、风道 | MOS 管铜箔过小→结温超限降频 |
| G 接口与连接器 | USB/CAN/电源座固定脚、插拔方向、防呆 | 只靠焊盘承力→拔插几次焊盘剥离 |
| H LED 与指示 | 电源/状态 LED 位置可視、限流电阻 | 状态灯被外壳遮住→现场无法判状态 |
| I 装配工艺 | 元件间距（返修烙铁空间）、丝印位号、极性标注 | 芯片间距过小→返修时拆一坏二 |

## 严重级别

- **必改**：不改大概率翻车（功能失效/量产事故/安全问题）
- **待确认**：视具体设计而定，需要计算或实测确认
- **提示**：经验建议，不做也能跑但留隐患



## 打勾工具（把清单变成可跑的检查表）

49 项手动对照容易漏，用打勾工具：逐项问过/没过/不适用，进度存档可跨会话续查，最后自动出整改清单（按严重级别排序）与有效通过率。

```bash
python scripts/pcb_check.py run --board "板子名"    # 交互逐项检查
python scripts/pcb_check.py report --board "板子名" # 查看结果与整改清单
python scripts/pcb_check.py list                    # 列出全部 45 项
```

## 工作流（升级版）

1. layout 完成 → 按类逐项自查（Gerber 打开 + EDA 3D 视图）
2. 每项记录：符合/不符合/不适用——不符合的截图存档
3. 输出整改清单 → 改版 → 只复查"必改"项
4. 打板前最后一遍：把本清单当 checklist 打勾过完
