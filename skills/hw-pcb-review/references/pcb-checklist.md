# PCB 布局自查清单明细（9 大类 49 项）

> 严重级别：**必改** / 待确认 / 提示。每项 = 检查内容 + 判据 + 典型事故。
> 使用：layout 完成后逐项打勾，不符合项截图存档出整改清单。

## A. 电源布局与去耦（8 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| A1 | **必改** | 去耦电容位置：每个电源引脚的去耦电容距引脚 ≤2mm，先大后小靠近引脚 | 去耦电容离芯片 3cm 以上 → 高频段去耦失效，电源纹波放大 |
| A2 | **必改** | DC-DC（Buck）功率环路面积：输入电容-上管-下管-电感环路最小化 | 环路大 → 开关噪声辐射，近场干扰整机 |
| A3 | **必改** | 大电流路径铜箔宽度：≥1A 用 40mil 以上或铺铜+过孔阵列 | 10mA/1mil 保守估算，电流密度过高 → 压降与发热 |
| A4 | 待确认 | LDO 输入输出电容按 datasheet 布局（ESR 敏感型注意） | 电容远离 → LDO 振荡 |
| A5 | 待确认 | 电源与敏感模拟区隔离：DC-DC 远离 ADC/运放/晶振 | 开关噪声耦合进模拟前端 → ADC 抖动 |
| A6 | 提示 | 电源指示灯限流电阻靠近 LED | 便于返修与目检 |
| A7 | **必改** | 多电源上电时序：FPGA/SoC/多轨系统按 datasheet 顺序上电（核心-IO-辅助），必要时加电源使能链或时序控制芯片 | 时序错 → 电流倒灌/闩锁/不起机（单电源板标不适用） |
| A8 | 待确认 | 外部供电产品的电源防反接：PMOS 理想二极管或肖特基；可反插的连接器必须处理 | 反接上电 → 烧板（内置电源/不可反插标不适用） |

## B. 回流路径与地平面（5 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| B1 | **必改** | 高速信号不跨分割：时钟/USB/CAN 走线所在层的参考平面必须完整 | 跨分割 → 回流绕行 → 环路天线辐射 EMI + 串扰 |
| B2 | **必改** | 地平面完整性：信号层下方避免大面积走线切断地 | 地被切成梳状 → 回流路径混乱 |
| B3 | 待确认 | 模拟地与数字地单点连接（有 ADC 的板） | 混接 → 数字噪声进模拟域；注意"单点"位置选在 ADC 附近 |
| B4 | 待确认 | 层叠设计：4 层板信号-地-电源-信号优于两层双层加粗 | 双层板做高速 → 阻抗失控 |
| B5 | 提示 | 屏蔽罩接地脚过孔就近接地，过孔数量足够 | 接地脚只有一个 → 屏蔽高频效果差 |

## C. 晶振与时钟（5 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| C1 | **必改** | 晶振下方禁止走线（任何信号线） | 晶振下走高速线 → 时钟抖动、偶发复位 |
| C2 | **必改** | 晶振负载电容靠近晶振（≤1.5mm），走线短而粗 | 走线长 → 寄生电容改变负载 → 频偏起振失败 |
| C3 | **必改** | 晶振包地（两侧地保护）+ 远离板边 ≥5mm | 板边晶振 → ESD/辐射敏感 |
| C4 | 待确认 | 多时钟域远离布置，避免互相耦合 | 时钟间耦合 → 混频杂散 |
| C5 | 提示 | 有源晶振电源加磁珠+去耦 | 电源噪声直接进振荡器 |

## D. 高速信号与阻抗（7 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| D1 | **必改** | USB 差分 90Ω 阻抗控制 + 等长（±0.5mm 内） | 不等长 → 眼图闭合、枚举失败 |
| D2 | **必改** | CAN 差分 120Ω 阻抗 + 端接电阻位置（总线两端） | 端接在收发器旁边而不是总线端 → 反射 |
| D3 | **必改** | 差分对内等长、对间距离 ≥3W | 对间耦合 → 串扰 |
| D4 | 待确认 | DDR/SDRAM 走线等长（按 data manual 的 skew 预算） | 等长超差 → 读写出错 |
| D5 | 待确认 | 阻抗与层叠匹配：向板厂要叠层参数算线宽 | 拍脑袋线宽 → 阻抗偏差 >15% |
| D6 | 提示 | 高速线换层时在过孔旁加回流地过孔 | 无回流过孔 → 阻抗突变点反射 |
| D7 | 待确认 | 以太网差分 100Ω 阻抗控制 + 对内等长，PHY 到网络变压器/RJ45 走线尽量短 | 阻抗失控 → 协商不稳/丢包（无网口标不适用） |

## E. EMC 与 ESD（6 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| E1 | **必改** | TVS 靠近接口连接器（先 TVS 后芯片） | TVS 靠芯片远 → 静敏器件先死 |
| E2 | **必改** | 接口地与信号地：外壳接地端子直接连板地（多点） | 外壳悬浮 → ESD 无泄放路径 |
| E3 | 待确认 | 共模电感/磁珠位置在接口入口处 | 滤波在板中间 → 噪声先耦合进板内 |
| E4 | 待确认 | 晶振/MCU 远离板边与接口（≥5mm） | 板边器件辐射最强 |
| E5 | 提示 | 未用 IO 引脚处理：输出低或输入加下拉，忌悬空 | 悬空 IO → 天线效应拾取干扰 |
| E6 | 提示 | 屏蔽线缆的屏蔽层 360° 环接（尾纤效果差） | 猪尾巴接地 → 屏蔽层变辐射天线 |

## F. 散热与热设计（4 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| F1 | **必改** | 功率器件（MOS/LDO/DC-DC）铜箔面积按功耗核算，热阻不够加过孔阵列 | 铜箔过小 → 结温超限 → 降频/寿命 |
| F2 | 待确认 | 热源分散布局，避免热堆积 | 多个热源挤一起 → 局部热点 |
| F3 | 待确认 | 有外壳时风道：进风口→热源→出风口方向合理 | 风道被电容挡住 → 散热效率减半 |
| F4 | 提示 | 温度敏感器件（晶振/基准源/电解电容）远离热源 | 电解电容烤 → 寿命骤减 |

## G. 接口与连接器（4 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| G1 | **必改** | USB/CAN/电源座固定脚焊盘接地且足够大 | 只靠信号脚承力 → 拔插几次焊盘剥离 |
| G2 | 待确认 | 插拔方向预留操作空间，防呆缺口 | 反插 → 上电即烧 |
| G3 | 待确认 | 调试口（SWD/UART）在板上引出且丝印标注 | 没引调试口 → 返修时开壳飞线 |
| G4 | 提示 | 连接器远离板边振动位，大质量器件加胶 | 振动环境虚焊 |

## H. LED 与指示（3 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| H1 | 待确认 | 电源/状态/通信 LED 位置可见（不被屏蔽罩/外壳遮挡） | 现场无法判状态 → 排障时间翻倍 |
| H2 | 提示 | LED 限流电阻选 1kΩ 级（功耗与亮度平衡） | 0Ω 直连 → LED 烧 |
| H3 | 提示 | 通信指示灯（TX/RX）便于观察联调 | 无指示 → 联调盲调 |

## I. 装配工艺（7 项）

| # | 级别 | 检查内容 | 判据/典型事故 |
|---|---|---|---|
| I1 | **必改** | 元件间距满足返修空间：QFN/BGA 周围 ≥1mm 无高件 | 密集 → 返修拆一坏二 |
| I2 | **必改** | 极性元件（电解/LED/二极管）丝印极性标注清晰 | 无标注 → 手工焊接反向烧板 |
| I3 | 待确认 | 丝印位号与 BOM 一致 | 位号错 → 贴片错料 |
| I4 | 待确认 | 板边器件距板边 ≥3mm（V-cut/传送边） | 贴片机吸嘴撞件 |
| I5 | 提示 | 测试点：关键电源/地/信号预留 testpoint | 无测试点 → 联调全靠飞线 |
| I6 | 提示 | 阻焊开窗：散热焊盘开窗（不盖油） | 盖油 → 焊接不良散热差 |
| I7 | 待确认 | SMT 贴片 Mark 点：对角 2~3 个光学定位 Mark（裸铜/镀层，远离板边与丝印遮挡） | 无 Mark → 贴片机光学定位失败拒贴（手焊板标不适用） |

---

## 使用建议

1. **打板前**：按类过一遍，"必改"项全清才能发板
2. **板回来异常**：先反查本清单——60% 的"玄学问题"是布局埋的
3. **外包 layout 验收**：把本清单作为验收附件
4. 与 `hw-review-checklist`（原理图）配合：**两张清单都过完才打板**
