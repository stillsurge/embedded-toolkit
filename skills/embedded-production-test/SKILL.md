# 产品出厂测试方案（embedded-production-test）

产线测试规范的**基础骨架**：L1→L4 四层模板，每项带操作方法与判定标准（判定值按产品规格填空）。
与 `embedded-unit-test-gen`（PC 侧单测）互补：单测管纯函数，本技能管**板级与量产**。

## 何时使用

- 新产品打板回来、准备小批量试产 → 生成 L1 规范
- 试产量产化 → 补 L2 老化与 L4 ESD 抽检方案
- 设计验证 → L3 温循/低温启动试验方案
- 产线换硬件/固件版本 → 复查四层规范是否需要增删

## 四层结构

| 层 | 时机 | 抽样 | 内容 |
|---|---|---|---|
| L1 功能全检 | 组装后 100% | 全检 | 上电电流/电源轨/时钟/通信/传感器/执行器/LED/按键/版本核对 |
| L2 老化 | L1 通过后 | 100% 或抽检 | 监控项（心跳/电流漂移/温度/复位计数）+ 老化后复测 |
| L3 温循/环境 | 设计验证+抽检 | 抽检 | 高低温循环、低温启动（常被漏掉的必测项） |
| L4 ESD 抽检 | 季度/改版后 | 抽检 | 放电位置/等级/A·B 性能判据分级/破坏品处置 |



## 规范生成工具（判定值填空 → 输出完整规范）

```bash
python scripts/spec_gen.py --board "板名" --model "型号" \
    --i-min 0.05 --i-max 0.8 --temp-max 75 \
    --low-temp -20 --high-temp 70 \
    --burn-hours 48 --esd-kv 4 \
    --profile 产线 -o spec_prod.md
```

- **两条产线一份证据**：`--profile 产线` 只含 L1/L2（发产线执行，节拍优先）；`--profile 工程`（默认）含全部四层 L1-L4（设计验证用）
- 生成版自带**通用记录字段节**（设备编号/校准有效期/批次号——没有它测试记录不可追溯）
- L1 节拍上限默认 2 分钟/台，`--takt` 按产线实际改
- 判定值全部命令行传入（来源三选一：设计规格书/评审纪要/试产实测），生成后人工复核一遍再发产线。全部参数见 `--help`。
## 使用流程

1. 读 `references/量产测试规范模板.md`（四层完整模板，判定值标 `________` 待填）
2. 按产品规格书逐项填判定值——**每个空都有来源要求**（设计规格/评审纪要/试产实测，不抄别家）
3. 生成产线版规范（只留 L1/L2），工程版（加 L3/L4）
4. 硬件或固件版本变更 → 复查测试项增删后升版规范

## 铁律

- **没有判定标准的测试不算测试**——每项必须写"多少算过"
- **固件版本必须记录**——版本不可追溯的测试记录等于白测
- ESD 测试后的机器不得混入良品出货
