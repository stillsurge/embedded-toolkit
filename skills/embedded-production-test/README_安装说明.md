# 产品出厂测试方案（embedded-production-test）

**产线测试规范的基础骨架——没有判定标准的测试不算测试。**

L1 功能全检 / L2 老化 / L3 温循与低温启动 / L4 ESD 抽检，四层模板判定值填空式（按产品规格书填），每项带操作方法、判定标准与记录字段。产线规范不是抄来的——每个判定值都有出处。

## 它解决什么问题

| 你遇到的 | 它给你的 |
|----------|----------|
| 小批量试产不知道产线要测什么 | L1 功能全检 9 项（上电电流/电源轨/时钟/通信/传感器/执行器/LED/按键/版本核对） |
| 老化测试没方案 | L2 监控项 5 个（心跳/电流漂移/温度/复位计数）+ 老化后必复测 |
| 低温翻车（晶振不起振/电解容骤降） | L3 温循+低温启动——最常被漏掉的必测项 |
| ESD 抽检没判据 | L4 A/B 性能判据分级（放电中可降级、放电后必须自动恢复） |
| 不良品混进良品 | 不合格品处置流程（红标签/隔离/返修重走 L1/批次停线规则） |

## 四层结构

| 层 | 时机 | 抽样 |
|---|---|---|
| L1 功能全检 | 组装后 | 100%（节拍 ≤2 分钟/台） |
| L2 老化 | L1 通过后 | 100% 或按批 |
| L3 温循/环境 | 设计验证+抽检 | 抽检 |
| L4 ESD | 季度/改版后 | 抽检 |

明细见 `references/量产测试规范模板.md`（判定值 `________` 填空式）。

## 作为 Agent Skill 使用

装进任意支持 Agent Skill 标准的 AI 助手后，直接说人话："帮我生成这块板的产线测试规范" / "老化测试要测什么、判多少" / "ESD 抽检方案怎么做"。

### 包结构

- `SKILL.md` —— 技能说明书（AI 按需读取）
- `references/量产测试规范模板.md` —— 四层模板明细（填空式）
- `scripts/spec_gen.py` —— 规范生成器（判定值命令行传入 → 输出完整四层规范 Markdown）

## 生成器用法

```bash
python scripts/spec_gen.py --board "板名" --model "型号" --i-min 0.05 --i-max 0.8 \
    --temp-max 75 --low-temp -20 --high-temp 70 -o spec.md
```

## 定位边界

**模板骨架而非现成规范**——判定值必须按你的产品规格书/评审纪要/试产实测填，不抄别家；本技能不替代安规认证（CE/UL 走认证机构）。

## 复核方式

四层判定值的复核：每项判定值回溯到三个来源之一（设计规格书条款/评审纪要/试产实测数据），来源不明的判定值重定。

## 真实输出样例

问：「老化测试方案怎么做？」

> **老化条件**：时长 48h（按失效率要求定）/ 高温 45℃ 加速 / 供电 110% / 满载轮换。
> **监控 5 项**（每 30 分钟）：通信心跳无失联、电流漂移 <5%、温度 ≤75℃、功能轮询全过、复位计数=0。
> **老化后必复测 L1 全项**——老化中活着不代表老化后没漂移，关键精度漂移 ≤2%。
> 【需自查：时长与温度按你的失效率要求和成本平衡填】
