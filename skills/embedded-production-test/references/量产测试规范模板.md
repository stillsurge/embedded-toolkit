# 量产测试规范模板（老化/温循/ESD 抽检/功能全检）

> 使用：量产量产线测试规范的基础模板，按产品实际情况填空。每个测试项必须写清
> 「判定标准」——没有判定标准的测试不算测试（NOT-TESTED 原则同样适用于产线）。

---

## 一、测试层级总览

| 层级 | 时机 | 抽样/全检 | 本模板覆盖 |
|---|---|---|---|
| L1 功能全检 | 组装完成后 100% | 全检 | ✅ §三 |
| L2 老化测试 | L1 通过后 100% 或抽检 | 按批次 | ✅ §四 |
| L3 温循/环境 | 设计验证阶段 + 量产抽检 | 抽检 | ✅ §五 |
| L4 ESD/EMC 抽检 | 每季度或改版后 | 抽检 | ✅ §六 |

---

## 二、通用记录字段（每张测试记录必含）

```
产品型号：________  硬件版本：________  固件版本：________
测试日期：________  测试员：________  批次号：________
测试设备：________（设备编号/校准有效期）
环境温度：________℃  环境湿度：________%
供电电源：________V（实测）  电源设备编号：________
```

> **铁律**：固件版本必须记录——版本不可追溯的测试记录等于白测。

---

## 三、L1 功能全检（100%，节拍 ≤2 分钟/台）

| # | 测试项 | 操作 | 判定标准 | 不合格处置 |
|---|---|---|---|---|
| 1 | 上电电流 | 稳压电源限流设为额定 ×1.5，上电读电流 | 电流在 [下限, 上限] 区间内（按设计值填）；无短路限流 | 直接判不良，标记短路位号 |
| 2 | 电源电压 | 万用表测各电源轨 | 每轨在标称 ±3% 内 | 判不良，记录实测值 |
| 3 | 时钟起振 | 示波器测晶振输出脚（或软件读时钟状态寄存器） | 频率在标称 ±50ppm 内；幅度达标 | 判不良，重点查 C1/C2 贴装 |
| 4 | 通信自检 | 上位机发握手命令 | 设备在超时时间内回复正确应答 | 判不良，区分"无回复/错回复" |
| 5 | 传感器通道 | 施加标准激励（已知信号源） | 读数在精度范围内 | 判不良，记录偏差值 |
| 6 | 执行器动作 | 软件触发输出 | 动作正常（继电器吸合/电机转动） | 判不良 |
| 7 | 指示灯 | 目检 | 各 LED 状态符合定义 | 判不良 |
| 8 | 按键 | 逐个按压 | 每键响应且无连击 | 判不良，记录键号 |
| 9 | 版本核对 | 读固件版本号 | 与当批要求版本一致 | **停线**——版本错误是批次性事故 |

**记录表**：每台一张 L1 记录，不合格项标红，不良品流入返修区时随附。

## 四、L2 老化测试（100% 或按抽检方案）

### 4.1 老化条件

```
老化时长：________ 小时（常见 4/8/24/48，按产品失效率要求定）
环境温度：________ ℃（常温老化）或 ________ ℃（高温老化，加速筛选）
供电：额定电压 ________%（如 110% 高压老化或 100% 标称）
负载状态：________（满载/典型负载/轮换负载）
```

### 4.2 老化中监控

| # | 监控项 | 采样周期 | 判定标准 |
|---|---|---|---|
| 1 | 通信心跳 | ≤1 分钟 | 老化全程无失联（一次失联即记录） |
| 2 | 工作电流 | 每 30 分钟 | 电流漂移 <____%（相对初始值） |
| 3 | 关键温度 | 每 30 分钟 | ≤________ ℃（结温/壳温按设计） |
| 4 | 功能轮询 | 每 15 分钟 | 全部功能项正常响应 |
| 5 | 复位计数 | 老化结束读 | 复位计数 = 0（任何非预期复位判不良） |

### 4.3 老化后复测

老化结束 **必须复测 L1 全项**——老化中"活着"不代表老化后性能没漂移：
- 关键精度项与老化前对比，漂移 ≤________%
- 复测不合格 → 判不良，**该批次加严抽样**

## 五、L3 温循/环境测试（抽检）

### 5.1 温循试验（设计验证必做，量产每批抽 ___ 台）

```
温度范围：低温 ________ ℃ ~ 高温 ________ ℃（按产品规格书工作范围）
循环次数：________ 次（常见 10/24/48）
驻留时间：每极端温度 ________ 分钟
转换速率：≤________ ℃/min（避免热冲击，除非特意做冷热冲击试验）
```

**温循中/后判定**：

| # | 检查项 | 判定标准 |
|---|---|---|
| 1 | 循环中功能 | 每个极端温度驻留期内功能正常（高温段和低温段各测） |
| 2 | 温循后外观 | 无开裂/变形/氧化变色 |
| 3 | 温循后精度 | 关键指标仍在规格内（对比常温基线，漂移 ≤____%） |
| 4 | 焊点 | 显微镜抽检 BGA/QFN 焊点无裂纹 |

### 5.2 低温启动（常被漏掉的项）

```
条件：低温 ________ ℃ 下静置 ________ 分钟后首次上电
判定：一次启动成功，时钟稳定，通信正常
典型坑：晶振低温不起振、电解电容低温容值骤降——此项必测
```

## 六、L4 ESD/EMC 抽检

### 6.1 ESD 抽检（接触/空气放电）

```
放电位置：所有外露接口（USB/CAN/电源座/按键/外壳缝隙）
放电等级：接触 ±________ kV，空气 ±________ kV（按产品等级：工业 4/8，消费 2/4）
放电次数：每点正负各 ________ 次
```

**判定（性能判据 A/B 分级）**：

| 等级 | 判定 |
|---|---|
| A | 放电中与放电后功能完全正常，无误动作 |
| B | 放电中允许性能暂时下降（通信中断/重启），放电后**自动恢复**且无需人工干预，数据无损坏 |
| 不合格 | 需断电重启才恢复 / 元件损坏 / 数据丢失 → 整改（查 TVS 位置与接地） |

### 6.2 抽检方案

```
抽样：每 ________ 台抽 1 台（或每批 ≥3 台）
抽样规则：随机取（不要总取同一工位/同一时段的）
破坏性说明：ESD 测试后的机器标注后降级处理或返工，不得混入良品出货
```

---

## 七、不合格品处置流程

```
不合格 → 标识（红标签+不良描述）→ 隔离区 → 返修 → 返修后重新走 L1 全检
批次不良率 >____% → 停线 → 查批次性原因（来料/工艺/版本）
所有不良记录进 MES/表格，按周做 Pareto 分析——top 不良项回溯到工位与根因
```

---

## 使用提示

1. 本模板的空必须**在量产前填完**——每空一个判定值，产线就多一分"凭感觉放行"
2. 判定值来源：设计规格书 / 评审纪要 / 试产实测数据——不抄别家产品
3. 模板随硬件/固件版本升版而升版：版本变更 → 复查测试项是否需要增删
