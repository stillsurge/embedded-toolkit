# 元器件选型避坑指南

帮所有自己买料的人——电子 DIY 爱好者、创客、硬件工程师、学生毕设——在**下单前**排掉采购雷：买到翻新料/假芯片轻则数据不达标重则炸板烧管——这些坑全部有前人踩过，下单前 5 分钟对照，省的是几周的调试时间。

**定位边界**：本技能是整理自公开讨论与前人踩坑经验的**静态知识库**，不附原始测试数据；价格给区间不给精确值，不代购、不推荐具体店铺或平台链接（渠道只给类型和辨别方法，店自己核）。

## 渠道分级（风险递增）

| 渠道类型 | 特点 | 适合买 |
|------|------|--------|
| **自营目录商城 / 授权分销商** | 自营采购、能追到原厂批次与授权链，datasheet 齐全 | **核心芯片、传感器**（毕设数据要交的件） |
| 开发板原厂官方店 | 板子+例程+教程配套 | 开发板、套件 |
| 平台认证的企业店 | 看企业认证与品牌授权书 | 模块类、连接器 |
| 个人店 / 二手闲置渠道 | **翻新/打磨/拆机件高发** | 仅限"坏了不心疼"的练手件 |

**原则一句话**：毕设要交测试数据的核心件走自营或授权分销；练手件才去拼低价。
**渠道只给类型不给名**——同类型里有好有坏，辨别方法比店名管用。

## 四类假芯片（识别特征）

| 类型 | 手法 | 危险度 |
|------|------|--------|
| **打磨改标** | 低端打磨成高端（国产运放→AD620、600V IGBT→1200V） | ⚠️ 最危险：轻则性能不达标，重则炸管烧板 |
| 翻新拆机 | 旧料翻新，坏块/掉电/寿命短 | Flash、传感器重灾区 |
| 白盒假冒 | 小作坊封装仿大厂外观 | PN532、MCP2515 重灾区 |
| 克隆片 | CS32 冒充 STM32（缺芯潮产物） | 多数外设对得上但非原厂，写明出处可接受 |

## 五步验真法（到货后、上电前）

1. **看包装**：原厂真空袋+湿度指示卡+型号/批次标签；散装塑料袋一把倒 → 警惕
2. **擦丝印**：棉签蘸丙酮或洗板水擦表面——原厂丝印牢固不掉色，翻新重打的一擦就花。⚠️ 溶剂通风、远离明火，先在不显眼的边角试（部分封装字会被溶剂咬掉，把好件擦成外观件）
3. **看背面**：手机微距镜头看划痕/磕碰/导热胶残留（拆机痕迹）
4. **查日期码**：同一盘日期码全同但外观不同 = 假；日期码晚于购买日期 = 假
5. **测参数**：万用表核对阻容标称值；关键件搭最小电路验证功能后再上整机

## 高频模块坑速查（DIY/创客/毕设最常用件）

| 模块 | 坑 | 正确买法 / 怎么量 | 依据 |
|------|-----|----------|------|
| SHT30 温湿度 | 兼容替代芯片温漂大、精度差 → 测试数据不达标。⚠️ 这是**现象类**说法，没有手册逐条对应 | 认准 Sensirion 原厂；判达不达标别看单点，**跟一支参考表同箱静置对比**（同一温湿度下两条曲线的差才是它的误差） | 公开资料（现象类·无手册判据） |
| MQ 系列气敏 | 裸探头只是加热丝+电极：手册的基本电路要 **VH 5V±0.1V** 供电加热、外部负载电阻 RL 分压，且**预热 24 小时以上**——上电就读就是乱跳 | 买带板载调理与基准电压的成品模块；用裸探头就照手册基本电路搭，**先预热再采**，别拿首读数当数据 | 手册（Winsen MQ135 / MQ-2 基本电路与参数表，见文末出处） |
| HC-05/06 蓝牙 | 买成 HC-06：**只能做从机、工作模式改不回来**，AT 命令集很少（改名/波特率那一类）。⚠️ 更正一个常见说法——HC-06 **不是"完全不能 AT"**，而是命令少且**必须在未配对状态下发** | 要主从切换或完整命令集就买 **HC-05 主从一体**；HC-06 发 AT 没反应，先确认它没连着手机/对端，再确认你发的命令在它那张短命令表里 | 公开资料（厂商手册特征句，见文末出处） |
| W25Q64 Flash | 翻新拆机件有坏块与掉电丢数据风险，且这类 NOR Flash **没有 ECC** | 发 `0x9F` 读 JEDEC ID 核对厂牌与型号（华邦以手册为准）；到手**全片擦一次再写读校验**，能直接挑出坏块；认准华邦/旺宏原厂+带排针成品 | 需自查（ID 与擦写校验都可直接测） |
| LM2596 降压模块 | 假芯片用 MC34063 冒充。LM2596 是 **150 kHz 固定频率**内部振荡器（手册逐字，见文末出处）；MC34063 手册写振荡**上限 100 kHz**，这类模块典型只跑 30-40 kHz → 纹波大、过热、带载能力掉 | 示波器看开关节点：**稳定 150 kHz 才像 LM2596**，明显低于 100 kHz 即假；关键供电买裸芯片自己焊或走自营 | 手册（150k/100k 两句）+ 需自查（示波器复验） |
| TP4056 充电模块 | 克隆片拆机报告：截止 4.27-4.37V 过充、早断 3.95V、无反接保护 | 到手先量浮充电压：原厂规格 **4.2V ±1%**（= 4.158-4.242V，手册逐字），明显高过 4.25V 就是过充风险；要反接保护直接换 ME4057（同板 drop-in） | 手册（4.2V±1%）+ 公开资料（克隆片那三个数是拆机实测） |
| 18650 电芯 | 虚标容量（标 4000mAh 实际不足一半）、翻新芯二次点焊 | 开路电压 3.6-3.9V、看带不带保护板；**称重只做同型号对比**（绝对克数因厂牌而异，别拿固定克数当判据）；要准容量就实充实放测一次 | 需自查（容量只有实测算数） |
| ESP32/ESP8266 模组 | 翻新料/剪板料：flash 缩水、缺加密加速器、重量偏轻 | `esptool flash_id` 核对 Flash 厂牌与容量（最硬的一条）；重量同样只做同型号对比 | 工具可判（esptool 输出即证据） |
| ATmega328P / FT232 | 假货高发（Arduino 板重灾区） | 两颗都**能直接读出来**，不用猜：ATmega 读签名字节，与 **Microchip 手册 "Device Signature" 一节**对照——⚠️ 别抄论坛，网上对 328 与 328P 各对应 `1E 95 0F` 还是 `1E 95 14` **说法互相矛盾**（老版 avrdude.conf 也错过）；FT232 看 USB 枚举 `0403:6001` 并装 FTDI 官方驱动试一次，克隆片常在新驱动上翻车 | 需自查（签名与枚举都可直接读） |
| 电源 | USB 口供电带载差、纹波大 → 复位/硬件故障 | 5V/3A 适配器+滤波电容；降压模块带过流过热保护 | 需自查（带载+纹波要实测） |
| 继电器 220V | 强电触电风险 | **断电接线+绝缘防护+先 5V 低压调通再上强电** | 安全红线 |

**依据口径**：**手册** = 我核过厂商手册原文（文末给逐字关键句与链接）；**公开资料** = 模块厂商或社区共识，我没逐字核；**需自查** = 只有你自己量才算数；**现象类** = 业内都这么说，但拿不出手册逐条对应，只能靠对比实验判。

## 缺货替代链（不 rework 方案）

| 缺货 | 替代 | 改动量 |
|------|------|--------|
| STM32F103C8T6 | GD32F103（国产） | CubeMX/HAL 九成可用，改启动文件与 Flash 等待配置 |
| SHT30 | SHT20 / AHT20 | 换 I2C 驱动即可（AHT20 命令与数据格式不同，要先发初始化命令），采集逻辑不变 |
| BH1750 光照 | 光敏电阻 + ADC | 换采集通道**并且重标 lux 曲线**——数字传感器变模拟，标定这段要重写 |
| BMP280 气压 | BME280 | 封装/管脚同，寄存器不同（芯片 ID 0x58 与 0x60、多一路湿度、校准区布局不同），驱动得改；注意 BME280 往往更贵也更缺，别当降级备胎 |
| HC-05 蓝牙 | CH340 有线串口 | 波特率/收发代码不变，先有线跑通；**代价是丢掉无线**，布局要能插线 |

## 分类采购策略

- **可以买便宜**：LED/点灯练手、简单驱动实验、坏了不心疼的消耗件
- **必须买正品**：电源与电机驱动（高压大电流=打磨改标高发）、精密模拟链路（称重/传感/音频——假运放漂移毁数据）、射频无线模块（假芯片射程与抗干扰差一个量级）、锂电池与充电电路（假芯片过充=起火风险）、**要交数据/要上线/要卖的核心件**

## 与配套技能的接力

- 传感器数据不对 → **embedded-debug-trees**（先分辨"选型坑"还是"接线坑"）
- 装了 mcu-debug-mcp 的用户：到手验芯片可直接用 `env_status`/串口日志排查假料引起的异常复位
- 教学场景（毕设/课程设计）预算总账与模块清单 → **grad-project-topic-advisor**（bom 模式，如已安装）

## 硬规则

1. **不编造价格**：只给区间，市场价波动大，下单前以商城实时价为准
2. **不推荐具体店铺或平台**：给渠道类型和辨别方法，店铺自行核验资质
3. **安全红线**：涉及 220V 的所有建议必须先提"断电操作+绝缘防护"，无例外
4. **拿不出测量方法的数字不许说**：多少克、多少丝印、差几倍这类没有判据的数，一律改写成"自己量什么"；分不清是手册值还是论坛值的，按"公开资料"档标
5. 标注体系：【需自查：价格与库存以商城实时为准】；教学场景可加【需导师确认：核心件选型】

## 手册出处（2026-10-27 核过的三条）

核法说明：**按厂商官方 PDF 的特征行核对，未逐页通读手册**；下列引号内为检索到的手册原文。

- **LM2596** — TI《LM2596 SIMPLE SWITCHER Power Converter 150 kHz …》与 onsemi《LM2596/D》："150 kHz fixed-frequency internal oscillator"、"The LM2596 series operates at a switching frequency of 150 kHz"
  <https://www.ti.com/lit/ds/symlink/lm2596.pdf> · <https://www.onsemi.com/download/data-sheet/pdf/lm2596-d.pdf>
- **MC34063A** — TI《MC3x063A 1.5-A Peak Boost/Buck/Inverting Switching Regulators》："Oscillator Frequency Up to 100 kHz"
  <https://www.ti.com/lit/ds/symlink/mc34063a.pdf>
  ⟹ 顺带纠一个流传口径：**"MC34063 只能跑 33 kHz"是典型应用值，不是芯片上限**；判假看实测开关频率，别套 33 kHz 这个数。
- **TP4056** — TOPPOWER（南京拓微）《TP4056 1A Standalone Linear Li-Ion Battery Charger》："final float voltage accuracy of ±1%"，充电电压固定 4.2V
  <https://datasheet.lcsc.com/Icsc/1809261820_TOPPOWER-Nanjing-Extension-Microelectronics-TP4056-42-ESOP8_C16581.pdf>

其余标"公开资料"的条目（SHT30 兼容料、HC-05/06 命令集差异）**没有逐条核到原文**，用前请自己复验。

另两条本轮新核到的：

- **MQ 系列气敏** — Winsen《MQ135》与《MQ-2》手册的 "Basic Test Circuit" 与参数表：传感器需要两路电压输入，加热电压 `VH 5V±0.1V` 与回路电压 `VC`，配外部负载电阻 RL；参数表列 **Preheat time: Over 24 hours**。
  <https://www.winsen-sensor.com/d/files/manual/mq135.pdf> · <https://www.pololu.com/file/0j309/mq2.pdf>
  ⟹ 由此把"裸探头数据乱跳"从机制猜测改成可核对的三条硬要求（加热电压、负载电阻、预热 24 h）。
- **HC-06** — 厂商《HC Serial Bluetooth Products User Instructional Manual》：HC-04/HC-06 属早期版本，**用户不能重设工作模式（主/从）**，且**只有少量 AT 命令可用**。
  <https://www.hestore.hu/prod_getfile.php?id=8278>
  ⟹ 所以原文"HC-06 不能 AT 配置"**说重了**，已改成"命令少 + 必须未配对时发"。第三方对照页也说 HC-06 在未配对状态下可用 AT 编程。

**一个反面样本，留着当提醒**：核 ATmega328P 签名字节时，检索到的公开页面**互相打脸**——有教程说 328P 是 `1E 95 0F`、要改成 `1E 95 14` 才能烧；另一份说 `0F` 才是 328P、`14` 是 328。老版 avrdude 配置也错过。
⟹ 本包因此**不写具体字节值**，只写"读签名 + 以 Microchip 手册 Device Signature 一节为准 + 论坛值有冲突"。这类"网上说不清"的数，给方法比给数字负责。
