# 元器件选型避坑指南（component-pitfalls）

**作用**：下单前和到货后各查一次，把"买了假货、性能不达标、炸管烧板"挡在装机之前。

当前版本 **1.0.0**：渠道四级、四类假芯片、五步验真、高频模块坑速查、缺货替代链。

## 渠道分级（风险递增）

| 渠道 | 适合买 |
|---|---|
| 自营目录商城 / 授权分销商 | 核心芯片、传感器——毕业设计要交测试数据的件 |
| 开发板原厂官方店 | 开发板、套件 |
| 平台认证的企业店 | 模块、连接器（看授权书） |
| 个人店 / 二手闲置 | 仅限坏了不心疼的练手件，翻新打磨件高发区 |

原则：核心件走自营或授权分销，练手件才拼低价。**只给渠道类型不点名**，辨别方法比店名可靠。

## 四类假芯片

| 类型 | 手法 | 危险度 |
|---|---|---|
| 打磨改标 | 低端打磨成高端（国产运放→AD620、600V IGBT→1200V） | 最高：轻则性能不达标，重则炸管 |
| 翻新拆机 | 旧料翻新，坏块 / 掉电 / 寿命短 | Flash、传感器重灾区 |
| 白盒假冒 | 小作坊封装仿大厂外观 | PN532、MCP2515 重灾区 |
| 克隆片 | CS32 冒充 STM32 | 外设多数对得上，写明出处可接受 |

## 五步验真（到货后、上电前）

1. **看包装**：原厂真空袋 + 湿度指示卡 + 型号批次标签；散装一把倒要警惕
2. **擦丝印**：丙酮或洗板水擦表面，原厂字牢固，重打的一擦就花（先在不显眼边角试，部分封装字会被溶剂咬掉）
3. **看背面**：微距看划痕、磕碰、导热胶残留
4. **查日期码**：同盘日期码全同但外观不同 = 假；日期码晚于购买日期 = 假
5. **测参数**：阻容核对标称值；关键件搭最小电路先验证功能

## 命令

知识型技能，无脚本。按 `SKILL.md` 的检索关键词定位条目，或直接问「买 XX 有什么坑」。

## 边界

不用于：芯片真实参数查询（以厂商 datasheet 为准）、电路设计审查（用 `hw-pcb-review` / 原理图审查）、失效分析。
