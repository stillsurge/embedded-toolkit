# 产品出厂测试方案（embedded-production-test）

**作用**：按板型和规格生成产线测试规范，把「没有判定标准的测试」变成可执行的检查表。

当前版本 **1.0.0**：L1–L4 四层规范模板 + 判定值填空生成器。

## 四层结构

| 层 | 时机 | 抽样 | 内容 |
|---|---|---|---|
| L1 功能全检 | 组装后 | 100% | 9 项通用测试项：上电电流、电源轨、时钟、通信、传感器、执行器、LED、按键、版本核对 |
| L2 老化 | L1 通过后 | 100% 或抽检 | 监控项（心跳、电流漂移、温度、复位计数）+ 老化后复测 |
| L3 温循 / 环境 | 设计验证 + 抽检 | 抽检 | 高低温循环、低温启动（最常被漏掉的必测项） |
| L4 ESD 抽检 | 季度 / 改版后 | 抽检 | 放电位置、等级、A/B 性能判据分级、破坏品处置 |

## 生成器

判定值按产品规格书填空，输出完整规范：

```bash
python spec_gen.py --board <板型> --model <型号> --i-min <下限> --i-max <上限> \
  --takt <节拍秒> --temp-max <温度> --low-temp <低温> --high-temp <高温>
```

参数还有老化时长/温度/电压/负载/抽样数、允许漂移、温循循环数与驻留时间。

## 铁律

每条测试项必须带判定标准；没有判定标准的测试不算测试。不合格品处置流程与记录字段一并给出。

## 边界

不用于：测试治具设计、自动化测试脚本（本技能产出规范，不产出上位机程序）、可靠性设计改进建议。
