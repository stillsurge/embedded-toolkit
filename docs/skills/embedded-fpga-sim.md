# FPGA 仿真工作台（embedded-fpga-sim）

**作用**：综合之前先把 RTL 功能在仿真里确认。管的是综合前，不是综合后调试。

当前版本 **1.0.0**：通用 testbench 骨架 + 6 类模块模板 + 判读要点。

## 模板清单

| 模板 | 覆盖判读要点 |
|---|---|
| 通用骨架 | 时钟复位时序、负沿驱动正沿采样、超时看门狗、VCD dump |
| 计数器/分频器 | 复位清零、off-by-one、使能冻结 |
| FIFO | 空读 / 满写 / 同时读写 / 满写不覆盖旧数据——四状态全覆盖 |
| CDC 打两拍 | 两域互质周期、脉宽 ≥ 慢域 2 周期、延迟固定 2 拍。**仅限单比特电平**，多 bit 走格雷码 / 握手 / 异步 FIFO |
| SPI 收发 | 采样沿对齐、回环逐位断言（MSB 先出）、全 0 / 全 1 边界 |
| UART 收发 | 起始位半位确认、中点采样、LSB 先出、停止位校验、波特率误差 ≤±2% |

`templates/` 下为可直接复制的 `.v` 文件。

## 判读要点

- X 态传播：未初始化寄存器导致的 X 会一路污染，先查复位覆盖面
- 复位完整性：同步复位还是异步复位、复位释放是否与时钟对齐
- 状态机非法态：未覆盖的编码是否会卡死

## 环境

仿真需本机 `iverilog`（Icarus Verilog）。技能本身是模板与判读知识，零第三方 Python 依赖。

## 边界

不用于：综合后行为异常与工具链排障（用 `embedded-fpga-trees`）、时序约束编写、板级调试。
