# 嵌入式代码生成器（embedded-code-generator）

**作用**：说清要什么模块和参数，直接得到可编译的 `.h + .c`，不用从零敲外设骨架。

当前版本 **1.1.1**：15 类模块，518 项 gcc 断言验证。

## 15 类模块

| # | 模块 | 关键参数 |
|---|---|---|
| 1 | PI 控制器 | Kp、Ki、Ts、输出限幅、抗积分饱和 |
| 2 | RS485 收发切换 | DE/RE 引脚、USART 实例、TC 标志 |
| 3 | 一阶低通滤波 | 截止频率、采样时间或 alpha |
| 4 | CRC 校验 | 缓冲区、长度；可选查表法（CRC8/16/Modbus/CCITT） |
| 5 | 环形缓冲 | 容量、元素类型、满策略（覆盖或拒绝） |
| 6 | SVPWM | 母线电压、PWM 周期 |
| 7 | 软件 I2C 主机 | SCL/SDA 宏、位延时、时钟拉伸 |
| 8 | SPI 主机 | mode 0~3、位序、片选极性 |
| 9 | ADC 均值滤波 | 采样函数指针、次数、去极值开关 |
| 10 | 有限状态机框架 | 转移表（源态/事件/目标态/守卫/动作）、进出回调 |
| 11 | DMA 环形接收 | 循环模式缓冲、硬件写位置换算 |
| 12 | 软件定时器 | 时基、周期、单次/周期、回调 |
| 13 | 命令行 shell | 命令表、最大参数数 |
| 14 | 轻量断言 | 记录/停机/复位模式、最大记录数 |
| 15 | 按键扫描消抖 | 键数、消抖/长按/连按阈值、有效电平 |

未指定的参数按推荐默认值直接产出，不反问。

## 代码质量

- Doxygen 注释、错误处理、边界检查齐备
- 518 项 gcc 断言验证（生成后用本机 `arm-none-eabi-gcc` 可选复验）
- 算法层不依赖平台，移植只改宏与回调

## 命令

按 `SKILL.md` 的「读取模板的方法」取模板文件，填参数后输出 `.h/.c`；`templates/` 下 30 个文件即 15 对。

## 边界

不用于：驱动移植参考（用 `embedded-driver-templates`）、代码审查（用 `embedded-code-reviewer`）、协议栈实现。
