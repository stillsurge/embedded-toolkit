# PCB 布局自查清单（hw-pcb-review）

**作用**：layout 阶段逐项打勾自查，每项标严重级别和典型事故，避免「原理图对了、布局翻车」。

当前版本 **1.0.1**：9 大类，分必改 / 待确认 / 提示三级。

## 9 大类

| 类 | 覆盖 | 典型事故 |
|---|---|---|
| A 电源布局 | DC-DC 环路最小化、去耦电容位置、大电流路径宽度 | 去耦电容离芯片过远，高频噪声无回路 |
| B 回流与地平面 | 地平面完整性、分割处理、跨分割信号 | 信号跨分割，回流绕行引起 EMI 与串扰 |
| C 晶振与时钟 | 晶振包地、时钟走线等长、远离板边 | 晶振下方走高速线，时钟抖动 |
| D 高速与阻抗 | 阻抗控制（USB/CAN/DDR）、差分等长、端接位置 | USB D+/D− 不等长，眼图闭合 |
| E EMC 与 ESD | ESD 器件位置、共模电感、屏蔽地 | ESD 器件离接口远，保护形同虚设 |
| F 散热 | 功率器件铜箔面积、过孔阵列、风道 | MOS 管铜箔过小，结温超限降频 |
| G 接口与连接器 | 固定脚、插拔方向、防呆 | 只靠焊盘承力，拔插几次焊盘剥离 |
| H LED 与指示 | 位置可视、限流电阻 | 状态灯被外壳遮住，现场无法判状态 |
| I 装配工艺 | 元件间距（返修空间）、丝印位号、极性标注 | 芯片间距过小，返修拆一坏二 |

## 用法

```bash
python scripts/pcb_check.py list                    # 全量清单，按 9 类分组输出，每项带级别
python scripts/pcb_check.py run --board "板名"       # 开始逐项打勾（写检查存档）
python scripts/pcb_check.py report                  # 出报告（需先 run）
python scripts/pcb_check.py reset                   # 清空存档
```

## 边界

审查对象是 **layout 阶段 PCB**，与原理图审查互补——原理图对了布局错了照样翻车。不用于：原理图功能审查、EMC 仿真、热仿真、DFM 厂规核验。
